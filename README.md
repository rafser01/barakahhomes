# Baraka Homes

A mobile-first property investment website built with Next.js, TypeScript, React and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```
